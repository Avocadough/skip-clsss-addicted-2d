A five-level 2D stealth-puzzle platformer set in a Thai school, created for **CP410844 by Group 19** with Godot.


Avoid teachers, guards and cameras while managing sight, noise, suspicion and items. Use a desktop keyboard; the controls, levels and team credits are documented below.

Open [game/project.godot](game/project.godot) in Godot 4.7 to explore the project. [game/scenes/](game/scenes/) contains levels and interface scenes, [game/scripts/](game/scripts/) contains gameplay logic, [game/tools/](game/tools/) contains development tools, and [docs/](docs/) contains the Web export. **The scene generator `bake.gd` overwrites existing scenes when rerun.**

## เนื้อเรื่องย่อ

เช้าวันหนึ่งก่อนคาบแรก **"น็อต"** นักเรียนมัธยมที่เหนื่อยล้าจากการบ้านและสอบย่อย
ได้ยินข่าวว่าคาบแรกจะมีการสุ่มสอบแบบไม่บอกล่วงหน้า เขาจึงตัดสินใจทำภารกิจที่ใหญ่ที่สุด
ในชีวิตนักเรียน — **โดดเรียนให้สำเร็จ**

แต่มันไม่ง่าย เพราะครูประจำชั้น หัวหน้าห้อง รปภ. กล้องวงจรปิด และเพื่อนที่ชอบฟ้อง
ต่างพยายามพาน็อตกลับเข้าห้องเรียน ผู้เล่นต้องพาเขาหลบผ่านโซนต่าง ๆ ของโรงเรียน
ไปให้ถึง "จุดโดดเรียน" ก่อนกริ่งเข้าเรียนจะดัง

## ระบบหลักในเกม

- **Countdown System** — เวลานับถอยหลังจนกริ่งเข้าเรียน คือแรงกดดันหลักของทุกด่าน
- **Suspicion Meter** — ค่าความสงสัยเพิ่มเมื่อถูกเห็นหรือทำเสียงดัง เต็มเมื่อไหร่ถูกส่งกลับห้องทันที
- **Line of Sight** — NPC และกล้องมีกรวยสายตาจริงที่ถูกกำแพง ตู้ และชั้นหนังสือบัง
- **Noise System** — วิ่งเสียงดัง เดินเสียงเบา หมอบเงียบสนิท เสียงดึง NPC เข้ามาตรวจ
  และใช้เป็นเครื่องมือล่อได้
- **Excuse Dialogue** — เมื่อหัวหน้าห้องเข้ามาถาม ต้องเลือกข้ออ้างให้ถูกสถานการณ์
  ตอบถูกลดความสงสัย ตอบผิดพุ่งขึ้น 34%
- **Inventory Puzzle** — ไอเทม 6 ชิ้น แต่ละชิ้นแก้สถานการณ์ต่างกัน

### ไอเทม

| ไอเทม | ผลในเกม |
|---|---|
| บัตรห้องพยาบาล | ลดความสงสัย 35% ทันที และใช้ชนะบทสนทนาได้ |
| เหรียญ 10 บาท | โยนไปไกล ๆ เสียงตกดึง NPC ให้เดินไปดู |

| ป้ายพื้นเปียก | วางขวางทาง NPC จะไม่เดินผ่าน 12 วินาที |
| ฮู้ดกันหนาว | ปลอมตัว 9 วินาที ลดโอกาสถูกจำได้ 75% และกล้องมองไม่เห็น |

## โครงสร้างโปรเจกต์

แต่ละด่านเป็น **ไฟล์ `.tscn` จริง** เปิดในหน้า 2D ของ Godot แล้วเห็นฉากทั้งด่าน
ลากแก้ได้ทันที ไม่ต้องแตะโค้ด — พื้นเป็น `TileMapLayer` วาดด้วย TileMap editor ได้
ครูแต่ละคนเป็น node ที่มี `kind` กับระยะเดินตรวจให้ตั้งใน Inspector

```
game/                     โปรเจกต์ Godot 4.7
  assets/sprites/         สไปรต์ทั้งหมด (สร้างด้วยสคริปต์)
  assets/audio/           เพลง 1 ไฟล์ + เอฟเฟกต์เสียง 16 ไฟล์ (.wav)
  assets/fonts/           Noto Sans Thai (SIL OFL)
  resources/              ชุดกระเบื้อง 1 ชุดต่อ 1 ธีมด่าน (.tres)
  scenes/
    boot / main_menu / level_select     หน้าจอหลัก
    levels/               ด่านทั้ง 5 — level_01.tscn ... level_05.tscn
    actors/               1 ไฟล์ต่อ 1 ตัวละคร: player (น็อต), teacher,
                          monitor, guard, librarian, coach, student,
                          student2, cctv
    items/                1 ไฟล์ต่อ 1 ไอเทม: item_key, item_coin,
                          item_hoodie, item_wetsign, item_nursecard,
                          item_notebook
    props/                ที่ซ่อน 7 แบบ (hide_locker ... hide_crate),
                          ประตู 2 แบบ, ลูกบอล, จุดหมาย, โซนบันได,
                          โซนห้องเรียน
    decor/                ของตกแต่ง: กระดานดำ นาฬิกา ถังขยะ ลัง
                          ชั้นหนังสือ ตู้กดน้ำ ป้ายทางออก ประตู
    ui/                   HUD, ช่องไอเทม, การ์ดเลือกด่าน, กล่องข้อความ,
                          หน้าจบด่าน, หน้าหยุดชั่วคราว, วิธีเล่น,
                          เกี่ยวกับเกม (รายชื่อสมาชิก), ฉากหลังเมนู, fader
  scripts/                ระบบเกมทั้งหมด
    game_state.gd         ความคืบหน้า ไอเทม บทสนทนา (autoload)
    audio_manager.gd      โหลดและเล่นไฟล์เสียง (autoload)
    level_data.gd         ค่าประจำด่าน (เวลา ชื่อ เป้าหมาย) + ผังตั้งต้นสำหรับ bake
    level.gd              คุมลูปเกม (ไม่ได้สร้างฉากเอง อ่านจาก .tscn)
    player.gd  npc.gd  cctv.gd
    entities/             ไอเทม ที่ซ่อน ประตู เป้าหมาย ลูกบอล โซนต่างๆ
    fx/                   แถบฉากหลังแบบ parallax
    ui/                   สคริปต์ของ HUD เมนู บทสนทนา
  tools/                  สคริปต์สำหรับพัฒนา (ไม่รวมในตัวเกม)
    assets.gd             วาดตัวละคร ไอเทม ไอคอน จากกริดพิกเซล
    themes.gd             วาดกระเบื้องและฉากหลังเฉพาะของแต่ละด่าน
    audio.gd              สังเคราะห์เพลงและเสียงทั้งหมดออกเป็นไฟล์ .wav
    bake.gd               สร้างไฟล์ฉากทั้งหมด — ด่าน หน้าจอ และ HUD
    validate.gd           ตรวจด่าน (อ่านจากไฟล์ฉากจริง): ของฝังในกำแพง
                          จุดที่เดินไปไม่ถึง เส้นทางเดินตรวจของ NPC ที่ถูกตัดขาด
    playtest.gd           ทดสอบเงื่อนไขชนะ/แพ้ทุกด่านอัตโนมัติ
    shot.gd               จับภาพหน้าจอทุกฉาก
    fliptest.gd           วัดตำแหน่งสไปรต์ตอนหันซ้าย/ขวา
docs/                     เว็บบิลด์ที่ GitHub Pages เสิร์ฟ
```

### แก้ด่าน

เปิด `game/scenes/levels/level_01.tscn` ใน Godot แล้วแก้ได้เลย:

| อยากทำอะไร | ทำยังไง |
|---|---|
| เพิ่ม/ลบพื้น | เลือก `SolidTiles` แล้ววาดด้วย TileMap editor |
| ย้ายครู | ลาก node ในหน้า 2D และตั้ง `patrol_min` / `patrol_max` ใน Inspector |
| เปลี่ยนครูเป็น รปภ. | ลบ node เดิม แล้วลาก `scenes/actors/guard.tscn` เข้ามาแทน |
| เพิ่มที่ซ่อน | ลาก `scenes/props/hide_bush.tscn` (หรือแบบอื่น) เข้ามา |
| เพิ่มไอเทม | ลาก `scenes/items/item_key.tscn` (หรือไอเทมอื่น) เข้ามา |
| แก้ครูทุกตัวพร้อมกัน | แก้ `scenes/actors/teacher.tscn` ครั้งเดียว ทุกด่านเปลี่ยนตาม |

แก้เสร็จรัน `validate.gd` เพื่อเช็คว่ายังเก็บของครบและครูยังเดินได้ตลอดเส้นทาง

> `tools/bake.gd` เป็นตัวสร้างไฟล์ฉากพวกนี้ขึ้นมาครั้งแรกจากผังใน `level_data.gd`
> **รันซ้ำเมื่อไหร่ ไฟล์ฉากจะถูกเขียนทับ** งานที่แก้ด้วยมือจะหายไปด้วย


### แก้หน้าจอและ HUD

หน้าจอทุกหน้าเป็น `.tscn` เหมือนกัน เปิดแล้วลากแก้ได้เลย เช่น
`scenes/ui/hud.tscn` (นาฬิกา แถบความสงสัย กระเป๋า) หรือ `scenes/main_menu.tscn`

หน้าตาของแต่ละหน้าเขียนไว้เป็น `static func build()` ในสคริปต์ของหน้านั้นเอง
ซึ่งเป็นตัวที่ `bake.gd` เรียกเพื่อสร้างไฟล์ฉากขึ้นมา — วางไว้ข้างกันแบบนี้
โค้ดกับไฟล์ฉากเลยไม่หลุดจากกัน ส่วนตอนเกมรันจริงจะโหลดไฟล์ฉากอย่างเดียว
ไม่ได้เรียก `build()`

โค้ดหา node ด้วยชื่อเฉพาะ (`%TimeLabel`) ไม่ได้ใช้เส้นทาง คุณเลยย้าย node
ไปไว้ตรงไหนใน scene ก็ได้ ไม่พัง

### สร้างเกมเอง

ต้องมี **Godot 4.7** พร้อม export template สำหรับ Web

```bash
# วาดสไปรต์ใหม่ทั้งหมด
Godot_v4.7-stable_win64.exe --headless --path game --script res://tools/assets.gd
Godot_v4.7-stable_win64.exe --headless --path game --script res://tools/themes.gd

# สร้างไฟล์เสียงใหม่ทั้งหมด
Godot_v4.7-stable_win64.exe --headless --path game --script res://tools/audio.gd

# สร้างไฟล์ฉากด่านใหม่ทั้งหมด (เขียนทับของเดิม)
Godot_v4.7-stable_win64.exe --headless --path game --script res://tools/bake.gd

# ตรวจด่านและทดสอบเงื่อนไขชนะ/แพ้
Godot_v4.7-stable_win64.exe --headless --path game --script res://tools/validate.gd
Godot_v4.7-stable_win64.exe --headless --path game --script res://tools/playtest.gd

# export เป็นเว็บ
Godot_v4.7-stable_win64.exe --headless --path game --export-release "Web" "../docs/index.html"
```

เว็บบิลด์ตั้งค่า **thread support = off** เพื่อให้รันบน GitHub Pages ได้
โดยไม่ต้องตั้ง COOP/COEP header

## หมายเหตุด้านงานภาพและเสียง

สไปรต์ทุกชิ้นในเกมนี้วาดขึ้นเองด้วยสคริปต์ `tools/assets.gd` จากกริดพิกเซล
ทำให้ตัวละคร ฉาก ไอเทม และไอคอนทั้งหมดใช้พาเลตต์เดียวกัน
(ม่วงพาสเทล ฟ้าอมเทา เหลืองนวล ชมพูอ่อน เขียวหม่น ตามที่ระบุในเอกสารออกแบบ)

ส่วน `tools/themes.gd` วาดของเฉพาะด่าน — ชุดกระเบื้อง 5 ชุดที่ใช้สีคนละโทน
